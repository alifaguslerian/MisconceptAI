# MisconceptAI

Web app untuk analisis miskonsepsi jawaban essay mahasiswa menggunakan LLM.

**Stack**: FastAPI · SQLite · React · Vite · Groq API (Llama 3)

**Status**: In development (thesis project)

## Fitur
- Input sesi ujian + jawaban ideal + konsep yang diuji
- Input jawaban essay per mahasiswa
- Analisis miskonsepsi otomatis via LLM
- Heatmap konsep × mahasiswa
